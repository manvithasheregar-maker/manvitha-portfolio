# Manvitha — Developer Portfolio

Responsive portfolio built with HTML, CSS, JavaScript, and Vite.

## Run in VS Code
1. Extract the ZIP and open this folder in VS Code.
2. Open Terminal → New Terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL shown in the terminal, usually http://localhost:5173/

## Production build
Run `npm run build`. The production files will be placed in `dist/`.

Edit page content in `index.html`, design in `style.css`, and interactions in `main.js`.

Content is based on the supplied Markdown portfolio documentation. Verify all personal and project details against your original resume before publishing. The original resume PDF was not included in this ZIP.
